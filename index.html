02Flagship

Apiary: a substrate for colonies of coding agents

Apiary applies stigmergy, the indirect coordination seen in ant colonies, to AI agents: each agent records its work in shared files, and the next agent reads them instead of receiving a message. Every claim, decision and task closure is a line in a version-controlled file, and no task closes until its acceptance check passes.

What I built. A language-neutral spec (SUBSTRATE_SPEC.md, 541 lines, each requirement with an ID), JSON test vectors for implementers, a conformance suite that talks to any implementation over MCP stdio, and a Python reference implementation: library, MCP server, CLI and a Claude Code guard hook. About 4,300 lines of implementation, 2,800 of unit tests and 1,200 of conformance harness.

How it is built. Test first, always. Every phase is pre-registered: plan, hypotheses and decision rules are committed before the first run. Five architecture decision records. A textbook-corrections.md lists where my own textbook was wrong, with evidence. The suite passes the reference and fails the textbook design as written, on purpose.

What it connects to. apiary connect add wires a colony to Blender, Godot, Aseprite, FFmpeg, SoX, Tiled and Inkscape, writes each program's known silent failures into its connector, and records a hash of every output it produces.

The working repository is private. A public demo edition is in preparation, and a live walkthrough is available on request.

03Evidence

Evaluation: the multi-agent design did not reduce cost

My textbook predicted that colonies of agents would be faster and cheaper than a single session. I committed the decision rules before the first run, ran 24 builds across two projects, and graded each one with hidden tests the agents never saw.

Median total tokens per build, by how the work was organised

Plain Claude Code session Colony, Queen works solo Colony with Forager subagents Measured
Quality: equivalent

Every arm hit 38/38 on the game. On the engine every run scored 315 to 317 of 317. The pre-registered test (worst colony run beats plain's best) was not met.

Cost: single sessions were cheaper

Forager subagents cost 3× to 7.7× the tokens. I redesigned the protocol around the data: solo by default, plan in one call, and the colony fell to 1.1× on the small game.

Value: an auditable record

All 15 colony runs closed every task on the first try through its acceptance check. After I added an approval guard, 6 of 6 runs asked the human before creating tasks, up from 1 of 3.

Use the colony for the record and the checks, not for a cheaper build.Apiary README, after Phase 8 · two projects, one machine, one model, three runs per arm
